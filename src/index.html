Capture par application

Windows : installer Npcap, puis lancer LanPulse en administrateur.

macOS : lancer avec sudo, ou installer « ChmodBPF » (fourni avec Wireshark) pour autoriser la capture sans sudo.

Linux : sudo setcap cap_net_raw,cap_net_admin=eip /usr/bin/lanpulse puis relancer.

Sans capture, LanPulse mesure quand même le débit total de la machine, l'historique, les réseaux et le partage entre machines.

Partage sur le réseau local

LanPulse diffuse toutes les 5 secondes, sur le port UDP 47321, le nom de cette machine, son système, le réseau et ses totaux de consommation. Aucun contenu de navigation, aucune application ni adresse visitée n'est partagé.
